# M4 전면 사진과 대조한 제한적 외관 패스

근거는 `R2026-SSM-I`, https://www.stagesoundkorea.com/수원청소년문화센터-조의형감독/ 의 2026 게시 전면 사진이다. 촬영일은 확인하지 못했다. 원본 사진은 저장소에 재배포하지 않는다.

## 이번 변경
1. Onnuri Art Hall의 사다리꼴 앞 장식을 낮은 삼각 박공으로 바꾼다. 사진으로 삼각 윤곽은 확인되지만 실제 높이·경사·재료 규격은 미실측이다. 기존 지붕판과의 연결면은 모델 틈 방지를 위한 기술적 근사이며 전체 지붕이 실제와 같다는 뜻이 아니다.
2. 기존 TrainingWing과 Onnuri 사이 빈 간격에 상부 연결층과 테라스 가장자리만 만든다. 아래쪽을 벽으로 채우지 않는다. 기존 건물의 실내나 객석은 삭제하지 않는다.
3. 사진에서 확인한 전면 좌측 외부계단을 기존 벽의 바깥에 간단한 18단 실루엣으로 나타낸다. 18단이라는 수와 단높이·너비는 시각 근사이며 사진에서 확인한 정확한 단수가 아니다. 난간과 착지 세부는 미완성이다.
4. 사진에 보이는 검정 띠가 있는 밝은 원주 6개를 광장에 추가한다. 사진 양쪽 끝은 잘려 있으므로 전체 시설의 총 기둥 수가 반드시 6개라는 뜻이 아니다. 위치와 간격·높이는 근사다.

## 보존·검사
M3 스크립트와 이전 커밋은 그대로 남긴다. M4도 단일 native와 그 native에서 내보낸 GLB가 같은 세계좌표를 사용한다. 역사 객석 번호석519/휠체어표시6, 시점6개, 재질계약은 유지한다. 출입·피난·접근성 인증이나 실측 결과는 아니다. 실제 렌더 `renders/m4-front.png`는 같은 M4 장면에서 생성한다. 사진합성이나 이미지생성 결과가 아니다.

## 재현
Blender5.3으로 `blender -b -t 4 -P blender/scripts/build_sycc_m4.py`를 실행한다. `verify_sycc_m4.py`는 공통 내보내기/좌석 검증에 중앙하부 통과선과 상부 연결층 raycast 검사를 추가한다. 이 검사에 통과해도 실제 건물과의 정확성이 증명되는 것은 아니다.

## 한정 로비 보행 메타데이터
기존 로비 바닥 안쪽에서 벽·벤치·객석을 피한 x34..44, glTF z-13..-6, floorY0.28 범위만 `WalkRegion_OnnuriLobby` Empty의 `walkRegion`으로 제공한다. eyeHeight1.65, spawn[39,1.93,-10], target[39,1.93,-6]. glTF 세계좌표를 직접 기록하며 node transform을 적용하지 않는다. 25개 하향 raycast로 바닥 높이를 표본검사한다. 전체 충돌·계단·문·접근성 구현이 아닌 제한된 평면 탐색 계약이다.
