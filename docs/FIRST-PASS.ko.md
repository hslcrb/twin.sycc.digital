# 첫 통합 검증 기록

계획을 먼저 커밋한 뒤 제작했다. 초기 외관과 역사 객석도 기반 모델을 브라우저용 자산으로 묶은 단계다. 전 시설과 전 층을 실측해 재현한 상태는 아니다.

- `models/sycc.blend` 323,840바이트. 이것이 유일한 Blender 원본이다.
- `public/models/sycc.glb` 1,268,656바이트. SHA-256 `bfc49c4eade9bc081956207683ed171aaef950fee226120fe0bd931ff8dec342`.
- 기본 GLB 장면: 노드 25개, 메시 19개, 재료 12개, 삼각형 23,808개, 드로 프리미티브 19개, 관측 위치 6곳. 드로 프리미티브와 화면별 실제 GPU 드로콜은 다르다. 모델 내부에 외부 파일 링크나 사진 텍스처가 없다.
- 실제 Blender 검사로 객석 519개, 별도 휠체어 위치 6곳, 원본과 내보낸 모델의 좌표·형상을 대조했다. 2017년 객석 배치를 따른 것이며, 현재 객석 실측이나 접근성 인증은 아니다.
- TypeScript 검사, Vite 빌드, 실제 GLB의 Three.js 파싱까지 포함한 뷰어 검사 9개, 모델 검사 4개 통과. 로컬 Vite 미리보기에서 HTML HTTP 200, GLB HTTP 200 `model/gltf-binary` 및 원본과 같은 바이트를 확인했다.
- Vite가 Three.js 포함 지연 로드 번들에 500kB 경고를 남겼다. 비교 기준: 초기 JS 약 3.36 kB(로컬 gzip 산출 1.63 kB), 3D 번들 약 632 kB(로컬 gzip 약 162 kB). 호스팅 전송 실측이 아니다.
- 렌더는 요청 시만 수행하며, 품질 모드와 상호작용 시 DPR을 조절한다. 실기기 GPU FPS와 네트워크 성능, 실제 보행 충돌, 승강기, 전체 실내를 검증하지 않았다.

다음 패스는 최신 배치와 시설별 외곽을 검증한 뒤 수영장·체육관·도서관과 공개 동선을 확장하고, 사진 기반 재료 관찰값 및 Blender에서 구운 텍스처, 하늘 반사 환경을 실제 GLB와 웹에서 대조한다.
