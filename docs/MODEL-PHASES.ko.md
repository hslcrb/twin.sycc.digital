# Blender 모델 M1 + M2 첫 패스 개발기

계획 커밋 `18258ecfc21e5eed3ee4652cf2bba9742ebc1dbf` 확인 후 구현을 시작했다. 실제 파일 위치는 계획의 예시 경로에서 `models/sycc.blend`와 `public/models/sycc.glb`로 확정했다. 생성 스크립트는 `blender/scripts/build_sycc.py`, 독립 검사 스크립트는 `blender/scripts/verify_sycc.py`다.

2025년 입구 사진 후보는 원본 URL에서404여서 사용하지 않았다. 관광공사 다른 이미지의 건물 식별을 확정할 수 없어 제외했다. 참조 사진과 도면 자체는 공개 모델 저장소에 복사하거나 텍스처로 사용하지 않는다. 공개 파일에는 URL·관찰 결과·자체 제작 형상만 남긴다.

## 블록아웃과 미확정 사항
전면 수평 3층동의 창호 리듬, 좌측 수직 탑 및 낮은 곡면, 후면 녹색 반복 지붕, 우측 온누리 입구, 광장 격자를 관찰해 근사했다. 사진과 실측 보정점이 없어 모든 좌표·거리·높이는 모델상 미터로 정한 근사값이다. 진북·지적 경계·정확한 건물별 배치는 미확정이다. 좌측 곡면과 후면 지붕동은 이름이 검증되지 않아 도서관/체육관/수영장이라고 단정하지 않고 neutral volume 명칭을 유지했다. 지하 수영장이나 비공개 설비·직원 공간은 임의로 상세화하지 않았다.

온누리 전실은 외부에서 유리를 통해 내부를 읽을 수 있게 빈 shell과 바닥을 두었다. 실제 전실 치수·가구 배치를 확인한 것은 아니다. 문 개폐·보행 충돌·승강기는 아직 구현하지 않았다. GLB waypoint는 관찰 카메라이고 피난·접근성·실제 동선 인증이 아니다.

## 객석도에 근거한 M2 초기 패스
1층 가/다 각 4행×8 + 9행×9 =113석. 중앙 나 블록은 앞8/9/10/11, 뒤12/11 교대8행으로130석이다. 1층 번호석356석. 2층 가/다는5행×9 + 3행×3=54석, 중앙5행×11=55석으로163석이다. 번호석 총519석에 1층 중앙 후방의 휠체어 공간 표시6을 합치면525가 된다. 이렇게 2017 번호석과 총 수용 구분으로 수치 차이를 설명할 수 있지만 최신 좌석 현황은 별도 확인 대상이다.

좌석마다 좌판·등판·기둥 형상을 만들고 재질별로 합쳤다. 좌석 수·행별 수는 도면을 따랐으나 좌석 폭, 통로 폭, 경사/단차, 무대 깊이, 발코니 높이는 미실측이다. 휠체어 공간6은 비워 둔 시각 표시이며 규격·접근경로의 적합성을 주장하지 않는다. 초안 생성 당시 실내 색은 중립적 짙은 회색으로 임시 지정했다. 이후 공식 https://www.syf.or.kr/web/resources/images/sub/infoImg02.png 사진에서 붉은 객석과 목재색 벽면이 확인되었다. 현재 회색 모델과의 차이를 숨기지 않으며 M3 재료 단계 수정 대상으로 남긴다. 사진에 없는 화려한 장식이나 실제처럼 보이는 임의 로고를 추가하지 않았다.

## 단일 원본과 재료·성능
건물·지형·좌석·창틀·광장·waypoint는 같은 Blender 원본에서 내보낸다. 뷰어에서 다른 건물을 다시 생성하지 않는다. Blender Z-up→glTF Y-up 변환은 위치[x,z,-y], waypoint target도 같은 방식으로 직접 기록한다. 카메라/조명은 GLB에 내보내지 않고 뷰어가 조명 환경만 제어한다.

석재·도장·포장의 native Noise/Bump는 자체 절차 재료다. 현재 GLB는 같은 기본 PBR 색/roughness를 사용하며 Blender 절차 노이즈를 텍스처로 bake하지 않았다. 두 렌더의 세부 표면이 완전히 같다고 주장하지 않는다. 유리는 alpha와 금속성·roughness를 이용한 저비용 시각 근사이며 실제 복층유리 광학 측정값이 아니다. 별도의 다운로드 사진·HDRI·텍스처는 없다.

반복 메시를 zone+material 기준으로 합쳐 draw call의 기본 비용을 줄였다. 내보낸 파일 크기, mesh/triangle 수와 해시는 model-manifest.json에 기록한다. 이 수치는 모델 자산의 크기이며 실제 기기의 FPS나 전송속도 측정을 대신하지 않는다.

## 재현과 검증
Blender5.3.0에서 실행했다. 명령은 각각 따로 실행한다.

```sh
blender -b -t 4 -P blender/scripts/build_sycc.py
```

```sh
blender -b models/sycc.blend -t 4 -P blender/scripts/verify_sycc.py
```

검사는 master/GLB hash와 길이, glTF header와 embedded buffer, source/GLB 삼각형 수, waypoint eye/target, 미터 단위, no missing image URI, metadata를 확인한다. 번호석과 휠체어 공간도 native 메시의 독립적인 면 개수와 공식 group count를 대조한다. 이런 통과가 사진과 완전 동일하거나 안전 보행 가능함을 뜻하지 않는다.

렌더 overview, onnuri-entry, onnuri-seats는 같은 실제 Blender 장면에서 만든 자체 스틸이다. 렌더용 카메라 변경은 저장된 마스터를 다시 쓰지 않는다. auditorium의 밝기를 읽기 위한 fill light는 시각화용이며 실제 조명 배치를 재현한 것이 아니다.

## 생성 병목과 조정
M2 첫 실행에서 좌석 부품마다 bpy.ops primitive 생성/transform을 반복하면 scene update 비용이 누적되어 저장 전 지연되었다. 이 초안을 중단하고 동일한 큐브 정점8개/면6개를 mesh data API로 직접 작성하도록 바꿨다. 변경 후 geometry 저장·export까지 약10초로 단축되었으며 좌석 수·형상 의도는 바꾸지 않았다. 이는 제작 스크립트 시간 개선이며 웹 FPS 개선 실측이 아니다.
